# My Portfolio 🚀

Welcome to my personal portfolio repository! This project showcases my skills, projects, and professional experience. It is designed to be fast, responsive, and user-friendly, featuring a working contact form powered by Node.js and Resend.

## 🌟 Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
- **Modern UI/UX:** Clean and minimalistic interface built with HTML, CSS, and JavaScript.
- **Dynamic Contact Form:** A fully functional contact form that sends emails directly to my inbox using the **Resend API**.
- **Backend Integration:** Powered by **Node.js** to handle email sending securely without exposing API keys to the frontend.
- **Project Showcase:** A dedicated section to display my latest work and contributions.
- **GitHub Pages Deployment:** Live and accessible via GitHub Pages.

## 🛠️ Tech Stack

**Frontend:**
- HTML5
- CSS3 (Custom styling & Flexbox/Grid)
- JavaScript (ES6+)

**Backend & Services:**
- Node.js
- Express.js (Optional, if used)
- Resend (For Email Delivery)
- Environment Variables (dotenv) for secure API key management
